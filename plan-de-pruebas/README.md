# Plan de pruebas - SauceDemo

Plan de pruebas y casos de prueba manuales para [SauceDemo](https://www.saucedemo.com/), sitio publico de practica tipo e-commerce (login, catalogo, carrito, checkout).

## Contenido

- `plan-de-pruebas.md` - objetivo, alcance, estrategia, criterios de entrada/salida, riesgos
- `casos-de-prueba.md` - casos de prueba funcionales (positivos, negativos y edge cases)
- `matriz-trazabilidad-automatizacion.md` - matriz de trazabilidad y cobertura entre QA manual y automatización (E2E, API y unitarias)

## Por que este proyecto

Muestra el proceso completo de diseno de pruebas manuales antes de automatizar: analisis de requisitos, identificacion de riesgos y escritura de casos de prueba claros y trazables.
